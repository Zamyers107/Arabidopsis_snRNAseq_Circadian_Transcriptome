# Arabidopsis_snRNAseq_Circadian_Transcriptome
bioRxiv doi: https://doi.org/10.1101/2025.06.12.659411


## Table of Contents
1. snTCFigures.rmd - R markdown file of figure generation
2. snTCfigures.html - stitched version of .rmd
3. Fig4B-E and S4 - code is provided as Jupyter notebooks
4. snTCprocessing.R - R code used to process and integrate single nucleus data
5. scGRNs - Contains three sequential scripts to generate scGRNs, as well as supporting network files
6. CycleJTK.WGCNA.Rmd - R code used to implement CycleJTK and WGCNA, as well as generate their associated figures
